When to pick it

pick it if
You run agents with tools (what it was trained for) and want a clean, sober result: every feature of its website worked.
watch out
Its own model card shows it does not code better than Qwen 3.5 9B. Its Snake moves one cell per screen refresh, so it is unplayable.
