Qwen3.6 35B A3B

Alibaba's mixture-of-experts model: 35 B parameters, about 3 B active for each token. With every expert kept in RAM, it runs on a 12 GB card using about 3 GB of video memory.

Pick it if
You have a 12 GB card and want the model that holds up when the job gets hard: it won all three tests, including the only real car crash.
Watch out
It saved its Snake game one folder above the folder it was given, so our automatic checker found nothing until we tested the file by hand.
