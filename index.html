How much memory does your graphics card have?

Estimate, not measured

We have only measured on a 12 GB card so far. This is an estimate from file sizes, not a measurement.

The 9B models (Qwen 3.5 9B, Ornith 1.5, NeoHorse 1) are 5.2 to 5.7 GB files and used 7.2 to 7.4 GB of our card with 64k of context. On 8 GB that is very tight: plan on a shorter context.

Mixture-of-experts models with the experts in system RAM used 3 GB or less of our card (Qwen3.6 35B A3B: 3.0 GB, LFM2.5 24B: 1.6 GB). They may run on 8 GB too, if you have 32 GB of system RAM.

How Kira tests

One real card
A second-hand RTX 2060 12 GB, with 32 GB of system RAM. Nothing rented in the cloud, and every result says which card it ran on.
Same jobs for everyone
Each model drives the Pi coding agent: one prompt, no help, 20 minutes. Then a script checks the result in a real browser. No model grades another model.
Failures shown
Too slow, broken game, nothing written in 20 minutes: it goes on the site too, with the files it wrote.
