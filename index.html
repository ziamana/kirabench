How Kira tests

Three rules, the same for every model.

real used cards
Consumer GPUs bought second-hand, the kind most people can actually afford. Nothing rented in the cloud, and every result says which card it ran on.
checked answers
Every task has an answer a script can verify: code that must pass its tests, numbers that must match. No model grades another model.
failures shown
Out of memory, broken output, too slow to use: it goes in the table too. That is the part leaderboards leave out.
